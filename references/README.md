# 论文架构图与示意图参考

共 30 张独立图，随附来源目录将其归于 27 篇 2025–2026 年会议论文。以 VGGT 为审美起点，收录信息凝练、箭头规整、模块排列清楚、配色克制等不同设计例子。图片由用户提供；论文元数据和裁切说明沿用原图集，不表示本仓库逐篇重新核验。

`figures/` 中是从论文 PDF 直接渲染并裁切的独立 PNG；保留整张 Figure 的所有子图、图内标签和图例，去除周围正文、图注和页码。图片未重绘、未改色、未重新排版。一般采用 450 dpi，较小的单栏图采用 600 dpi。

编号 01–10 可先看；后续扩展到深度估计、视频抠图、多模态、图像编辑、语音、语言建模、表格、时间序列与机器人控制。28–30 是已收录论文中另外选出的完整模块图。
